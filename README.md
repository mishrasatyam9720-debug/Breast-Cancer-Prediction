# 🩺 Breast Cancer Prediction

## 📌 Overview
This project predicts whether a breast tumor is **Benign** or **Malignant** using a Machine Learning classification model. The project was developed in **Google Colab** using Python and the scikit-learn library.

## 🚀 Features
- Data preprocessing
- Train-test split
- Model training
- Prediction on test data
- Model accuracy evaluation

## 🛠️ Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## 📂 Dataset
The Breast Cancer Wisconsin Dataset is used for training and testing the model.

## 🤖 Machine Learning Model
- Support Vector Machine (SVM)

> *(Agar Logistic Regression use kiya hai to SVM ki jagah Logistic Regression likh dena.)*

## 📊 Results
The model was trained and evaluated using the test dataset to predict whether the tumor is benign or malignant.

## ▶️ How to Run
1. Open the notebook in Google Colab.
2. Install the required libraries (if needed).
3. Run all cells.
4. Enter the input values (if applicable) to make predictions.
